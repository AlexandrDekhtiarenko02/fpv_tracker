# Где что лежит и как ко всему подключиться

Этот файл — точка входа. Если контекст переписки потерян, читать первым.

## Доступ

| | |
|---|---|
| Малина | `ssh alex243@Monolith.local` (вход по ключу, пароль не нужен) |
| Код на малине | `/home/alex243/fpv_tracker` |
| Логи | `/home/alex243/fpv_tracker/flight_logs` |
| Служба | `tracker.service` (systemd, автозапуск) |
| Репозиторий | `github.com/AlexandrDekhtiarenko02/fpv_tracker`, приватный |
| Доступ малины к репозиторию | ключ развёртывания, **только чтение** |
| Полётник | GEPRC F405, датчики ACC + BARO + GYRO, по USB `/dev/ttyACM0` |
| Камера | IMX219, трекинг по 320x240 (яркость), кадр 640x480 |

`sudo` на малине **требует пароль** — команды с ним выполняет оператор.
Команды с `ssh` рассчитаны на запуск с компьютера; если запускать их НА
малине, она полезет по ssh сама в себя и спросит пароль.

## Ветки

| Ветка | Что содержит | Состояние |
|---|---|---|
| `main` | защита от неоднозначного матча, контур управления, логирование, оценка сближения | база, проверена |
| `color-guard` | `main` + отсев по цвету + измерение адаптации размера + журнал опытов | **лучшая на сейчас**, цвет подтверждён оператором |
| `search-window` | `main` + окно поиска от размера цели | провалов 18% → 8%, **не объединена с цветом** |
| `exposure` | `search-window` + ограничение выдержки | отвергнута, дело не в выдержке |
| `psr-radius`, `match-weight`, `seeker-zoom`, `launch-acceleration` | отработанные опыты | влиты или отвергнуты, см. журнал опытов |

**Не сделано:** объединить `search-window` и `color-guard`. Оба дают выигрыш,
вместе не проверялись.

## Что проверено в воздухе, а что нет

**Проверено на стенде оператором:** всё по трекингу (см. `experiments.md`).

**НЕ ПРОВЕРЕНО В ПОЛЁТЕ вообще:** весь контур управления — разгон по углу,
устранение ратчета газа, привязка ко времени, оценка сближения, высотомер.
Проверялось только на моделях и стендом. Первый реальный вылет с этим кодом
ещё предстоит.

## Как понять, что летит

```bash
cd ~/fpv_tracker && ./status.sh
```
Сверяет md5 запущенного процесса с файлом на диске. `git pull` меняет файл, но
служба продолжает выполнять код, загруженный в память при старте — перезапуск
обязателен.

## Обновить код на малине

```bash
cd ~/fpv_tracker && git pull && sudo systemctl restart tracker && sleep 6 && ./status.sh
```

## Развернуть на новой малине

```bash
git clone git@github.com:AlexandrDekhtiarenko02/fpv_tracker.git
cd fpv_tracker && ./setup_pi.sh
```
